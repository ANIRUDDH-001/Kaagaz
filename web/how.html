How Kaagaz works

Understand → confirm → remember → follow through → escalate. Gemma decides what a paper means; Temporal makes sure it gets done.

The loop

  1. A photo of a paper, or a spoken instruction in Hindi, Hinglish or English.
  2. Gemma 4 extracts the amount, the last date, the action and the consequence, each with the exact words it came from.
  3. A confirmation card reads it back in Hindi. Amounts or dates the paper doesn't support are highlighted. Nothing is saved until the tap.
  4. A Temporal workflow reminds 30, 7 and 1 days before. If it's still not done, the son is told.

Architecture

Browser (this page, static, never sleeps)
   │ photo / voice / text, confirm, done, snooze
   ▼
API on Render (sleeps when idle) ───► MongoDB Atlas: obligations, inbox, history
   │  + Temporal workers
   ▼
Temporal Cloud: timers, retries, signals ◄── GitHub Actions worker, 4× an hour
   │
   ├─ Gemma 4 (hosted 26B, or E4B on a laptop)
   ├─ Speech-to-text (ElevenLabs Scribe, or Whisper on a laptop)
   ├─ Hindi voice (ElevenLabs, or the browser)
   └─ Web Push

Temporal holds every timer, so reminders don't depend on the API being awake. Workflows carry only IDs and dates; content stays in the database. Photos and recordings are never stored.
